Direct the model

Fast drafts or full-resolution detail.

Choose the model that fits the moment. Use Lite for fast 1K exploration, or the default Gemini image model for richer output up to 4K.

DEFAULT · GEMINI IMAGELITE · FAST 1K512 → 4K
creative-session — zsh
# Generate a cinematic wide image
nb generate "a glass pavilion in a pine forest" \
  --size 2k --aspect-ratio 16:9 \
  --output pavilion.jpg

# Change only the atmosphere
nb edit pavilion.jpg \
  "replace daylight with blue hour" \
  --output pavilion-blue.jpg

# Fast 1K concept
nb generate "playful banana sticker" --model lite
